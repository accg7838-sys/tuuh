# Богд хаант Монгол — Эдийн засаг, соёл

1911–1919 оны Монголын эдийн засаг, соёлын тухай 9 илтгэгчийн, 36 слайдтай веб танилцуулга.

Төслийн код, локал зураг болон фонтууд `bogd-museum/` дотор байна.

## Ажиллуулах

```sh
cd bogd-museum
node server.mjs
```

Node.js байхгүй Mac дээр `ruby server.rb` ашиглаж болно.

Browser: http://127.0.0.1:4173
