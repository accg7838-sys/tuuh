# Богд хаант Монгол · Эдийн засаг, соёл

9 илтгэгч, 40 минут, нүүр + 36 тайз. Монгол кирилл агуулга, 10 архивын дүрслэл, локал Noto Serif / Noto Sans фонт. Үндсэн танилцуулга, ярих эх интернетгүй ажиллана. Эх сурвалжийн гадаад холбоос нээхэд интернет хэрэгтэй.

## Ажиллуулах

Энэ Mac дээр `start.command` файлыг нээх эсвэл Terminal-д:

```sh
cd /Users/babuna/tuuh/bogd-museum
ruby server.rb
```

Browser: http://127.0.0.1:4173

Node.js суулгасан компьютерт `node server.mjs` эсвэл `npm start`. Python 3 суулгасан компьютерт `python3 -m http.server 4173 --directory dist` ашиглаж болно. Шинэ сан татах шаардлагагүй. `file://` хэлбэрээр шууд нээхгүй: ярих эхийн JSON-ыг HTTP-ээр уншина.

Серверийг зогсоох: `Ctrl+C`. Порт завгүй бол `PORT=4174 ruby server.rb` эсвэл `PORT=4174 node server.mjs`.

## Нэмэгдсэн тайз, ярих санаа

Өмнөх 18 тайзыг 36 болгож өргөжүүлсэн. Хүн бүр 3–5 слайдтай; нийт 40 минутын хуваарь өөрчлөгдөөгүй. Слайд бүрд шууд ярьж болох 2–3 өгүүлбэрийн “Ярих санаа” ил харагдана. Бүтэн ярих эх `N` самбарт хэвээр. Дэлгэцийн доод талд тогтмол байрлах жижиг цэгүүдээр тухайн хүний слайдуудаас сонгоно. Дараах слайд баруунаас, өмнөх слайд зүүнээс 0.85 секундэд гулсаж орж ирнэ. Reduced motion үед шууд шилжинэ; слайдын дээд талын дугаар, хугацааны мөрийг арилгасан.

Parallax нь зургийн гүн, эсрэг чиглэлийн хөдөлгөөн, хэвтээ чимэглэл, архивын зөөлөн эргэлт/ойртолт, галерейн нээлт, том түлхүүр үгсээр ялгарна. Хөдөлгөөн гүйлгэлтээс хамаарна; ярих өгүүлбэр тогтвортой байна. Mobile дээр далайцыг багасгана.

Илтгэгчийн нэртэй дээд мөрүүдийг арилгасан. Бичвэр 1.25 секундэд зөөлөн, дараалсан сааталтай нээгдэнэ. Бүх тайзны гол бичвэр хажуугаас дараалан нээгдэнэ; нүүрний гарчиг, дэд гарчиг доороос дээш гарна. Reduced motion үед бичвэр шууд харагдана.

## Удирдлага

Доод удирдлагын мөрийг арилгасан. Дээд мөрийг мөн бүрэн арилгасан. Бүтэн дэлгэцийг `F` товчоор удирдана.

- `1`–`9`: тухайн илтгэгчийн эхний тайз.
- `→` / `PageDown`: дараах тайз. `←` / `PageUp`: өмнөх тайз.
- `F`: бүтэн дэлгэц. `Esc`: drawer эсвэл бүтэн дэлгэцээс гарах.
- `N`: тухайн илтгэгчийн бүтэн ярих эх; анх хаалттай.
- Баруун талын 01–09 навигац; URL hash хадгалж refresh хийх боломжтой.
- Төгсгөлийн “ЭХ СУРВАЛЖИЙГ ҮЗЭХ” товч: судалгааны холбоос, зураг бүрийн зохиогч, огноо, лиценз.

Browser Fullscreen API-г хязгаарласан үед ердийн дэлгэц ажиллана. Browser-ийн өөрийн fullscreen командыг мөн ашиглаж болно.

## Засварлах

- `dist/data.js`: 9 хүний нэр, хугацаа, гарчиг, өнгө, 36 тайзны агуулга. `talk` нь дэлгэцийн “Ярих санаа”, `motion` нь тухайн тайзны parallax хэв маяг.
- `dist/notes.json`: 9 хүний бүрэн ярих эх.
- `dist/source-material.md`: өгсөн MD-ийн бүтэн хуулбар.
- `dist/assets-manifest.json`: зураг бүрийн эх URL, зохиогч, огноо, лиценз, хэрэглээ.
- `dist/assets/`: зураг болон фонтууд. Font license: `FONT-LICENSE.txt`.
- `dist/style.css`, `dist/app.js`: зохиомж, хөдөлгөөн, удирдлага.

Бүх агуулга статик; backend, бүртгэл, гаднын CDN байхгүй. `dist/` нь шууд байршуулж болох production багц. `node scripts/verify.mjs` нь агуулга, JS синтакс, локал assets-ийн бүрэн бүтэн байдлыг шалгана.

## Зураг ба үнэн зөв байдал

Зургийн зорилтот 12–18-ын оронд эх сурвалж, лиценз нь тодорхой 10 дүрслэл сонгосон. Зарим нь хэд хэдэн тайзанд дахин ашиглагдана. Commons metadata-г хадгалсан. Жүгдэрийн панорамын дижитал хуулбарын огноог бүтээлийн 1913 онтой андуурахгүйгээр бүртгэсэн. Богд хааны хөргийг 1911 оны яг зураг хэмээн тайлбарлаагүй.

Сургуулийн болон “Шинэ толь”-ийн баталгаатай эх зураг олдоогүй тул үсэг, он, тайлбарын зохиомж ашигласан. Сонины эх хувийн хуулбар биш гэж тэмдэглэсэн. Монгол–Төвөдийн гэрээний зургийг төсвийн данс хэмээн тайлбарлаагүй. Номын бүрэн эхийг уншсан мэт эшлээгүй; өгсөн ярих эхийн түүхэн баримтыг өөрчлөөгүй.

## Баталгаажуулалт

Chrome дээр 1366×768, 1920×1080, 390×844 хэмжээнд зохиомж, хэвтээ халилт, зураг/фонтын ачааллыг шалгасан. 36 тайз болон 36 ярих санааны бүрэн бүтэн байдал, навигац, слайдын цэгэн товч, тоон товч, ярих эх, drawer хаалт, таймерийн эхлэх/түр зогсох/шинэчлэх, эх сурвалжийн бүртгэлийг шалгасан. Browser console-д алдаа гараагүй.

Автомат browser орчин Fullscreen API-г зөвшөөрөөгүй тул бүтэн дэлгэцийн амжилттай нээлтийг баталгаажуулаагүй; fallback хэвийн. Reduced-motion хувилбар нь CSS media query болон JS matchMedia-ээр parallax, clipping, том шилжилтийг унтраана; OS тохиргоог өөрчилж туршаагүй.
